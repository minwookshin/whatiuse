# 0.1.0-rc.40

This candidate closes the internal RC verification loop without changing component APIs.

- Storybook interaction tests now run through an ASCII-safe temporary workspace when the repository path contains spaces or non-ASCII characters.
- Runtime evidence measures the public Button and Dialog interactions instead of the retired product-pilot route.
- Public documentation and visual evidence use the consolidated 67-route surface.

Existing component imports, props, CSS variables, and registry item names do not require migration.
