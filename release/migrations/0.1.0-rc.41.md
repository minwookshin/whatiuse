# 0.1.0-rc.41

This candidate expands whatiuse Data with independent, source-owned components rather than a combined workflow surface.

- Data Table adds controlled column ordering alongside the existing visibility, sizing, and pinning contracts.
- Column Manager, Editable Cell, Query Builder, and Export Progress are individually installable.
- Saved Views can copy a shareable view link, Bulk Action Bar can preserve reversible completion, and Data State includes a permission boundary.

Existing Data imports remain available. `ColumnVisibilityMenu` remains a compatibility wrapper around `ColumnManager`.
