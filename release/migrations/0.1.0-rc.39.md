# 0.1.0-rc.39

This candidate adds dedicated flyout motion tokens for anchored temporary surfaces.

- Use `--whatiuse-flyout-enter-duration` for tooltip, menu, select, combobox, context switcher, and popover entrances.
- Use `--whatiuse-flyout-exit-duration` for their exits.
- Keep `--whatiuse-enter-duration` and `--whatiuse-exit-duration` for dialogs, sheets, and larger temporary surfaces.

The change is additive. Existing overrides keep working, and component props do not require migration. Analytics tooltip positioning is now shipped as a source-owned registry dependency without changing the public component API.
