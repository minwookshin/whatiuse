# 0.1.0-rc.42

This candidate finalizes Expansion 1 as independent Data components and keeps the existing workflow recipes optional.

- Data Table adds controlled column ordering alongside visibility, sizing, and pinning.
- Column Manager, Editable Cell, Query Builder, and Export Progress are individually installable.
- Saved Views can copy a shareable view link, Bulk Action Bar supports reversible completion, and Data State includes a permission boundary.
- The complete-system stylesheet now emits one component layer without changing component cascade order.

No existing Data import was removed. `ColumnVisibilityMenu` remains a compatibility wrapper around `ColumnManager`.
