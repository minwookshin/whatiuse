# 0.1.0-rc.43

This candidate closes Expansion 1 as separately installable Data components.

- The registry recipes now import `ColumnManager` from its own component module.
- A clean React + TypeScript consumer can install, type-check, and build the complete Data collection.
- React 18 and React 19 keep the same public component contracts.

No existing Data import was removed. `ColumnVisibilityMenu` remains a compatibility wrapper around `ColumnManager`.
